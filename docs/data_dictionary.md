# Data dictionary

| Field | Source | Use |
|---|---|---|
| Tmax/Tmin | CE Hub forecast/history | heat/frost stress |
| rainfall | CE Hub forecast/history | drought/yield/N/P factors |
| ET | CE Hub derived forecast/history | drought index |
| soil moisture | field/user input or available source | drought/N/P factors |
| GDD | calculated from weather | yield risk |
| soil pH | field/user input | yield/P stress |
| N applied | farmer/field input | NUE |
| P applied | farmer/field input | PUE |
| projected yield | field/user/model input | NUE/PUE |

The organizer's documentation is the primary source. No external dataset is required for the core prototype.
